# Stage 2 — Two-Node Thermal Model

## Physical model

The model has two lumped thermal nodes:

- **Component:** uniform temperature `Tc`, capacitance `Cc = mc cp,c`.
- **Wall:** uniform temperature `Tw`, capacitance `Cw = mw cp,w`.

Heat generated by the component crosses the solid conduction resistance

`R_cond = L / (k A_cond)`

and then leaves the wall through convection

`R_conv = 1 / (h A_conv)`.

The governing balances are

`Cc dTc/dt = Q_gen - (Tc - Tw)/R_cond`

`Cw dTw/dt = (Tc - Tw)/R_cond - (Tw - T_inf)/R_conv`.

The model assumes constant properties, constant heat generation, fixed ambient
temperature, no radiation, no internal-air node, no contact resistance, and no
other heat path. Both nodes are spatially uniform. It is therefore a compact
lumped two-node model, **not a three-dimensional enclosure/CFD simulation**.

## Analytical validation

At steady state:

`Tc,ss = T_inf + Q_gen (R_cond + R_conv)`

`Tw,ss = T_inf + Q_gen R_conv`.

The transient benchmark is obtained independently from the eigenvalues and
eigenvectors of the linear two-state system. The numerical solver uses classical
RK4 and shortens the final step so the final time is exactly the requested
duration.

## Single-node limit

As `R_cond -> 0`, the component and wall temperatures equilibrate rapidly and
tend toward a common temperature. The consistent lumped limit has combined
thermal capacitance `Cc + Cw` and convection resistance `R_conv`:

`(Cc + Cw) dT/dt = Q_gen - (T - T_inf)/R_conv`.

Its steady state is `T_inf + Q_gen R_conv`, and its time constant is
`(Cc + Cw) R_conv`. This comparison is only valid when both physical masses are
included in the single lumped node; it is not a comparison with Stage 1's
component-only capacitance.

## Numerical tolerance

The baseline Stage 2 run uses `dt = 0.1 s`. Its maximum difference from the
independent eigen-solution is approximately `8.20e-8 K` for the component and
`2.05e-8 K` for the wall. A separate automated transient test at `dt = 0.25 s`
uses a documented `2e-3 K` tolerance because the deliberately coarser step
resolves the faster thermal mode less accurately.

## Stage 3 engineering applicability

Stage 3 adds systematic sensitivity studies without changing the two-node
model interface. The study grids, analytical trend checks, numerical benchmark
verification, Biot check and environmental scenario assumptions are documented
in `STAGE3_ENGINEERING_VALIDATION.md`.

The lumped-capacitance applicability criterion is checked only where the
necessary geometry and material properties are available. For the illustrative
Al 6061-T6 wall reference, `L_c = V/A_conv` and `Bi = h L_c/k` are used. A small
Biot number supports a nearly uniform wall temperature for that assumed case,
but it does not validate the enclosure model or the selected convection
coefficient.

The high-altitude study uses standard-atmosphere temperature/density values and
an explicitly stated simplified forced-convection scaling. Altitude alone is
never treated as a universal determinant of `h`.
